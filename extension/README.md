# 미믹 클라우드 저장 (브라우저 확장)

웹페이지의 마그넷·토렌트·영상·파일 링크를 찾아 미믹 클라우드에 저장하고, 매일 출석 체크를 하는 Chrome·Edge 확장입니다(Manifest V3).

## 오프라인 설치

1. 미믹 웹 **설정 > 액세스 및 통합**에서 `mimic-extension.zip` 을 내려받아 압축을 풉니다.
2. Chrome 은 `chrome://extensions`, Edge 는 `edge://extensions` 를 엽니다.
3. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드**(Edge: 압축을 푼 확장 로드)를 눌러 `mimic-extension` 폴더를 고릅니다.
4. 도구 모음의 미믹 아이콘 → **미믹 계정 연결** → 열린 탭에서 승인합니다.

## 쓰는 법

- 링크·영상·이미지에서 오른쪽 클릭 → **미믹 클라우드에 저장**
- 아이콘을 누르면 이 페이지에서 찾은 링크 목록이 나옵니다. 고른 뒤 **선택한 링크 저장**
- 같은 창에서 **출석 체크**를 누르고 연속 출석 일수를 확인합니다
- 설정 화면에서 받은 zip 에는 그 서버 주소가 기본값으로 들어 있습니다. 다른 서버를 쓰려면 확장 **설정**에서 주소를 바꿉니다
