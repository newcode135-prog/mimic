## 1. 한 줄 요약

**미믹은 사용자가 외부 링크(마그넷·토렌트·HTTP URL·SNS 게시물)를 붙여넣으면 미믹 서버가 대신 내려받아 그 사용자의 미믹 클라우드에만 저장하고, 웹·앱에서 바로 재생·정리·공유할 수 있게 하는 클라우드 드라이브 서비스입니다.**

- 벤치마크 대상: PikPak(mypikpak.com, 운영사 PikCloud Pte. Ltd.)
- 목표: PikPak의 기능 76개를 **1개도 빠짐없이 같은 동작**으로 구현
- 첫 서버: **맥미니 1대**(사무실/자택 설치, 베타 운영)

## 3. 미결정 사항 (진행 전에 사용자에게 확인)

1. **토렌트 기능의 국내 법적 분류**: 공유 기능과 결합 시 "특수유형 부가통신사업자(웹하드)" 등록·기술적 필터링 의무 대상인지 변호사 검토 필요
2. **서비스 지역**: 국내 전용 / 글로벌. 글로벌이면 글로벌·지역 프리미엄 2등급과 다국어·해외결제가 필요
3. **실제 판매 가격(원화)**: 8장의 PikPak 가격은 참고값
4. **PG사**: 토스페이먼츠 / 포트원. 암호화폐·Alipay·UnionPay 포함 여부
5. **맥미니 단계의 용량 정책**: 맥미니 1대로는 "프리미엄 1인당 10TB"를 감당할 수 없음. 베타 기간 한도를 정해야 함(11장)
6. **토렌트 시딩 정책**: "우리 클라우드 안에만"을 지키기 위해 다운로드 중 업로드 속도를 제한하고 완료 즉시 시딩을 멈출지(제안). 단, 업로드를 너무 막으면 다운로드 속도가 떨어짐
7. **도메인·사업자 정보**: 통신판매업 신고, 개인정보처리방침에 들어갈 정보
8. **상표**: "미믹/Mimic" 선등록 상표 조사(KIPRIS)
9. **"A와 B의 중간" 해석 확인**: 2장 표 아래의 해석이 맞는지
10. **프리미엄 만료 뒤 금고 데이터**: 금고는 프리미엄 전용이라 만료되면 열거나 꺼낼 수 없다. 이 데이터를 드라이브 초과분처럼 단계적으로 지울지, 보관 기간·사전 알림을 따로 둘지(지우면 되돌릴 수 없음)
11. **토스 자동 결제(빌링키) 저장 방식**: 구독 자동 갱신에 필요한 빌링키를 서버 암호화 키로 암호화해 둘지(규약 0-7은 비밀 값을 해시로만 저장) — 토스 빌링 계약과 함께 결정

## 4. 벤치마크 대상(PikPak) 요약

- **정체성**: 토렌트·마그넷·URL·SNS 링크를 서버가 대신 받아 개인 클라우드에 저장하고 바로 스트리밍 재생하는 서비스
- **핵심 가치 3가지**
  1. 클라우드 다운로드: 사용자 기기가 꺼져 있어도 서버가 받아 둠. "80% 이상이 수 초 안에 완료"라고 표방(서버에 이미 있는 파일은 즉시 복사하는 중복 제거 구조로 추정)
  2. 스트리밍 재생: 4K 원본 또는 자동 해상도
  3. 프라이버시: 통신 암호화, 파일 미스캔·AI 학습 미사용·광고 미사용 표방, 종단간 암호화 금고(Vault)
- **접점 9개**: 웹 드라이브, Android, iOS, Windows, macOS, TV(Android TV), 브라우저 확장(Chrome·Edge), 텔레그램 봇, CLI·WebDAV·MCP
- **공식 한계**: 업로드 쿼터 있음, 로컬 사진·문서 자동 동기화 없음

## 5. 핵심 사용자 흐름

1. **가입**: 로그인 화면 → 방식 선택(6종) → 휴대폰은 인증코드만으로 자동 가입, 이메일은 인증코드 + 비밀번호 → 무료 6GB 드라이브 진입(기본 폴더 "My Pack"과 튜토리얼 영상이 미리 들어 있음)
2. **저장**: "클라우드 다운로드" 버튼 → 링크 붙여넣기(여러 개는 줄바꿈) 또는 토렌트 파일 선택 → 저장 폴더 선택 → 서버가 보유 여부 확인 → 있으면 즉시 완료, 없으면 다운로드 대기열 → 완료 시 드라이브에 저장하고 알림
3. **재생·내려받기**: 파일 선택 → 무료 720p / 프리미엄 원본 → 기기로 내려받으면 다운스트림 쿼터 차감
4. **공유**: 파일·폴더 선택 → 만료일·비밀번호 설정 → 공유 링크 생성 → 받은 사람은 보기 또는 자기 드라이브로 저장
5. **업그레이드**: 한도 도달(하루 3회·6GB·하루 20GB) 안내 → 결제 페이지 → 상품·결제수단 선택 → 결제 → 등급 즉시 반영
6. **만료**: 8-6의 5단계 순서로 제한 → 알림 → 초과분 자동 삭제

## 7. 로그인·계정 상세

| 방식 | 동작 | 구현 |
| --- | --- | --- |
| Google | "Google 계정으로 계속하기" | OAuth 2.0 / OpenID Connect |
| Facebook | 페이스북 로그인 | Facebook Login |
| Apple | Apple로 로그인, "이메일 가리기" 중계 주소 대응 | Sign in with Apple(iOS 앱에 소셜 로그인을 넣으면 사실상 필수) |
| 휴대폰 | 국가번호(한국어 화면 기본 +82) + SMS 인증코드. **미가입 번호는 자동 가입**. "비밀번호 로그인" 전환 링크 | SMS 발송 대행사. 개발 모드에선 코드를 서버 로그에 출력 |
| 이메일 | 로그인: 이메일 + 비밀번호, 비밀번호 찾기. 가입: 이메일 + 인증코드 + 비밀번호(문자·숫자·기호 혼합 6~16자) + 확인 | 비밀번호는 scrypt 해시 |
| QR 코드 | 웹 화면에 QR 표시 → 로그인된 모바일 앱으로 스캔 → 앱에서 승인 → 웹 로그인 | 일회용 QR 토큰(짧은 유효시간) + 앱 승인 + 웹 세션 발급 |
| CLI | `auth login` → 브라우저에서 승인 | OAuth 기기 인가 방식. CLI로 만든 미인증 계정은 72시간 안에 인증, 미인증 시 잠금 후 12개월 뒤 삭제 |

- 로그인 화면 하단에 약관·개인정보 동의 문구. 국내는 필수/선택 동의 분리, 만 14세 미만 처리 기준 필요
- 반복 실패 시 "시도 횟수 초과" 제한
- 계정 메뉴: 계정 및 보안 · 피드백 · 로그아웃
- 계정 및 보안 7개 탭: 계정 정보(프로필 사진·사용자 이름), 비밀번호, 휴대폰, 이메일, Facebook 계정, 연결된 앱, 계정 해제
- 소셜 가입 계정은 비밀번호가 없고 나중에 설정 가능
- **탈퇴**: 신청 즉시 오프라인 → 7일 안에 다시 로그인하면 자동 복구 → 7일 후 데이터 완전 삭제, 연결된 휴대폰·이메일은 새 가입에 재사용 가능. 법 위반·도난 위험이 있으면 탈퇴 처리 중지 가능
- 연락처 변경: 기존 연락처에 접근할 수 없으면 고객지원 이메일로 증빙 제출
- 지역 판정: IP·기기 언어·SIM 국가코드, 현지 휴대폰 번호 연동으로 보정
- 보안 제안: 인증코드 5분 유효·60초 재전송 제한, 기기별 세션 목록·원격 로그아웃, 2단계 인증 추가

### 8-5. 결제 정책

- 구독은 월·연 단위 자동 청구, "구독 관리"에서 해지, "구매 기록" 페이지 별도
- 구독 중 1회 상품을 사면 멤버십 기간 연장
- 결제 버튼 = 멤버십 약관 동의
- 첫 구독 할인은 해지 후 재구독 시 다시 주지 않음
- 체험 코드: 자동 결제 없음, 종료 전 알림
- 결제 후 혜택 미반영 시 문의 채널
- 환불(PikPak): 원칙적으로 불가(불가항력 제외), 청구 오류 30일 내, 실수 구매 + 미사용 24시간 내. **국내는 전자상거래법 청약철회 7일 등과 충돌 가능 → 미믹 환불 규정은 국내법 기준으로 새로 작성**
- 정기결제 무료→유료 전환·가격 인상은 사전 동의 필요(국내 규정)

### 8-6. 프리미엄 만료 후 처리 순서

1. 일반 등급으로 전환, 로그인·파일 관리는 가능
2. 용량 초과 시 업로드·새 클라우드 다운로드·새 저장 차단
3. 만료 7일 후 온라인 재생 중지, 기기 다운로드 100KB/s로 제한
4. 초과 상태 4개월 경과 후 2개월 유예 + 알림(총 6개월)
5. 이후 15~30일 안에 초과분을 오래 수정된 파일부터 자동 삭제(복구 불가)

추가 저장공간은 만료 시 동결.

### 8-7. 전송 쿼터 상세

- 모든 사용자에게 월 기본 쿼터: 클라우드 다운로드 40TB, 다운스트림 4TB, 업로드 1TB. 매월 초기화, 이월 없음
- 기본 쿼터를 먼저 쓰고 추가 쿼터 사용
- 업로드 계산량은 압축 때문에 파일 크기보다 작을 수 있음
- 무료: 다운스트림 하루 20GB, 하루 0시 초기화(미믹은 KST)
- 연결 앱(WebDAV·CLI·서드파티) 합산 상한 = 각 월 쿼터의 25%(추가 쿼터 아님). 초과 시 다운로드 약 100KB/s 감속, 업로드 차단, 새 클라우드 다운로드 차단(진행 중 작업은 계속). 공식 앱은 상한 없음. 무료는 연결 앱 다운로드 하루 5GB
- 쿼터 상세 페이지에서 항목별 사용량 표시
- 예상 밖 한도 도달 시 계정 도용·공유·비공식 앱 사용 점검 안내

### 8-8. 초대 보상

- 초대한 친구가 가입 후 1년(365일) 안에 결제하면, 친구가 산 프리미엄 일수의 **35%**를 초대자에게 프리미엄 일수로 지급(예: 월 구독 4회 → 42일, 연 구독 → 128일)
- 한 달에 초대한 사용자 중 **10명이 구매할 때마다 업로드 트래픽 100GB** 추가, 최대 5TB, 다음 달 말까지 유효
- 초대 방식 3가지: 설치 링크, 파일 공유, 추천인 코드. 전용 설치 파일 배포 가능
- 초대 성공 판정: 초대 링크로 설치 후 앱에서 로그인. 가입 후 12시간 안에 초대 관계를 맺어야 인정
- 구매로 인정: 구독, 인앱 구매, 프리미엄 코드, 체험 코드. 무료 코드·증정 기간은 제외
- 보상은 30분 안에 지급. 같은 기기·계정 등 이상 데이터는 걸러내고, 부정 참여는 회수
- 초대 기록 보기
- 추천 보상 Pro: 현금 보상형(조건 미확인)

### 8-9. 기타 혜택

- 출석 체크: 브라우저 확장에서 매일 출석하면 무료 프리미엄
- 쿠폰 코드: 상단 메뉴에서 등록, 코드 구매 링크

### 10-5. 규칙

- API: `/api/<모듈>/...`, JSON, 오류는 `{ "error": "코드", "message": "설명" }`
- 인증: 쿠키 세션(웹) 또는 `Authorization: Bearer` 토큰(앱·CLI·연동). 권한 범위: `files:read`, `files:write`, `files:manage`, `files:delete`, `services`, `account`
- 파일 저장: 업로드·다운로드 결과를 SHA-256으로 저장하고 `files`가 참조. 참조가 0이 되면 본문 삭제
- 클라우드 다운로드 엔진: 플랜별 동시 작업 수(무료 1, 프리미엄 5), 대기열, 실패 재시도, 토렌트 infohash 캐시로 즉시 완료, 차단 목록 검사, 스마트 필터, 결과는 **요청한 사용자의 미믹 드라이브에만** 저장
- 영상: ffmpeg로 HLS 변환(무료 720p, 프리미엄 원본), 내장 자막 추출(WebVTT), 오디오 트랙 선택
- 금고: 브라우저에서 AES-GCM 암호화(키는 패스코드에서 PBKDF2로 유도), 서버는 암호문만 저장
- 개발 모드: 이메일·SMS는 실제 발송 대신 `outbox`에 저장하고 `/dev/outbox`에서 확인. 소셜 로그인·PG 키는 환경변수로 받고, 없으면 해당 버튼에 "설정 필요" 표시
- 테스트: 모듈마다 `test/<모듈>.test.js`(node:test)

## 11. 맥미니 서버 구축 계획

### 11-1. 하드웨어

| 항목 | 권장 |
| --- | --- |
| 본체 | Mac mini(Apple 실리콘), 메모리 24GB 이상 권장(영상 변환·토렌트 동시 처리), 내장 SSD 512GB 이상(OS·DB·임시 파일) |
| 파일 저장소 | Thunderbolt/USB 외장 디스크 2개 이상을 미러(RAID 1)로 구성하거나 NAS 사용. 시작 용량 예: 2×12TB 미러 = 실사용 약 12TB |
| 전원 | UPS(무정전 전원장치) — 정전 시 DB 손상 방지 |
| 회선 | 업로드 속도가 서비스 품질을 좌우함. 가능하면 기업용 대칭 1Gbps 이상. 가정용 회선은 서버 운영 제한 약관이 있는지 통신사에 확인 |

### 11-2. 맥미니 단계의 현실적 한계 (정직한 수치)

- 실사용 12TB 저장소로는 "프리미엄 1인당 10TB"를 약속할 수 없음 → 베타 기간에는 `server/core/plans.js` 값으로 한도를 낮춰 운영(예: 프리미엄 100GB~1TB). 중복 제거로 실제 사용량은 줄어듦
- 동시 시청자 수는 회선 업로드 속도에 묶임(예: 1Gbps 업로드 ≈ 원본 화질 10~20Mbps 영상 수십 명)
- 영상 변환(ffmpeg)은 CPU를 많이 씀 → 변환 결과를 캐시하고 동시 변환 수 제한
- 그래서 맥미니는 **클로즈드 베타용**. 사용자가 늘면 10-6 순서로 확장

### 11-6. 네트워크·도메인·HTTPS

- **권장안**: 도메인 구매 → 공유기에서 80·443 포트를 맥미니로 포워딩 → **Caddy**가 HTTPS 인증서를 자동 발급하고 `localhost:4300`으로 전달. 고정 IP가 없으면 DDNS 사용
- 대안: Cloudflare Tunnel(포트를 열지 않아도 됨). 단, 대용량 영상 전송은 Cloudflare 약관상 제한될 수 있어 사전 확인 필요
- 토렌트 수신 포트(예: 51413) 포워딩은 다운로드 속도 향상용(선택)
- 토렌트 트래픽은 회선 명의자에게 저작권 통지가 갈 수 있음 → 차단 목록·신고 처리 절차를 출시 전 갖출 것(13장)

### 11-7. 백업·모니터링

- DB: 매일 SQLite 온라인 백업(`.backup`)을 별도 디스크 + 외부(오브젝트 스토리지)로 복사, 30일 보관
- 파일 본문: 미러 디스크 + 중요도에 따라 외부 백업. 백업 범위를 이용약관에 명시
- 디스크 남은 용량 경보(예: 15% 이하), 외부 가동 감시(업타임 체크), 로그 순환(newsyslog)
- 비밀값은 `.env`에만, 저장소에 넣지 않음

### 11-8. 확장 순서 (사용자 증가 시)

1. 저장소를 NAS 또는 S3 호환 오브젝트 스토리지로 이전(`server/core/storage.js`만 교체)
2. 클라우드 다운로드·영상 변환 작업을 별도 작업 서버로 분리
3. DB를 PostgreSQL로 이전
4. 영상 전송에 CDN 적용

## 15. 이 프로젝트를 이어받는 AI의 작업 규칙

1. PikPak의 로고·이미지·CSS·화면 문구·약관을 복사하지 말 것. 기능·정책 수치·화면 구조만 같게 하고, 보이는 것과 문장은 미믹 고유로 만들 것
2. 외부 링크로 받은 파일은 요청한 사용자의 미믹 클라우드에만 저장할 것
3. 3장의 미결정 사항은 임의로 정하지 말고 사용자에게 물어볼 것
4. 기능은 6장 ID로 추적하고, 구현이 끝나면 ID별로 "구현됨 / 테스트됨 / 미확인"을 보고할 것
5. 정책 수치(용량·쿼터·가격)는 `server/core/plans.js` 한곳에 모아 맥미니 단계에서 조정 가능하게 할 것
6. 비밀번호는 해시로만, 토큰은 해시로만 저장. 비밀값은 `.env`에만
7. 개발 모드에서는 실제 이메일·SMS·결제를 보내지 말고 outbox·테스트 모드로 처리할 것
8. 각 모듈은 자기 폴더·파일만 수정하고, 코어 변경이 필요하면 이유를 남길 것
9. 모듈마다 실행 가능한 테스트를 남길 것(`node --test`)
10. 사용자는 비개발자일 수 있으니 결과 보고는 한국어로, 전문용어는 풀어서 설명할 것
